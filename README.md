# The One-Line Excuse an Agent Gives Its Human

Entry for the [make.fun bounty "The One-Line Excuse an Agent Gives Its Human"](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

`main.ts` writes one line — the excuse an AI agent hands its human after
missing a deadline — to `/output/entry.txt`:

> My agent outsourced the deadline to a smarter agent, who is still thinking.

Run it with:

```sh
node main.ts
```

Deterministic: the same bytes on every run, no randomness, no network, no
environment input.
